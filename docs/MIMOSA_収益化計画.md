# MIMO$A 収益化計画

**出典**: としさんとのミーティング（音声メモ整理）  
**目的**: 20万円を作り、プロモーション資産を揃えたうえで現金も持ち帰る  
**ステータス**: ドラフト（メモ末尾「マリンエクスプレスの」で途切れ・要追記）

---

## 1. 結論（やること）

1. **マリンエクスプレスはやる** — Review Booster を **ケータイ100円** で回せる営業として即着手
2. **目の前の千円・二千円・三千円を取りに行く仕組み**を先に回す（大きく考える前に小さく取る）
3. **MIMO$A で20万**を作り、その枠内で「定価50万相当の機材／サービス＋プロモ動画＋ダーウィンMV」を揃える
4. **プラス1人10万**持ち帰りを狙うなら、動く量を今より広げる

---

## 2. としさんからの原則（マインド）

| 原則 | 解釈 |
|------|------|
| お金にもっと貪欲になる | 「後で」ではなく、今ある現金導線を取りに行く |
| 普通は20 | 案件・目標の単位感は **20万** が基準 |
| 目の前の千円〜三千円を取りに行く仕組み | 単価が小さくても **仕組み化**して積み上げる |
| 広く動いて広く考える | 一箇所・一案に閉じない。レプリカ・観光客・マリン等へ面を広げる |
| 1日1万円稼げなくて良い | 日次ノルマより、**仕組みと20万ゴール**を優先 |

## 3. キャッシュ導線（すぐ動く）

### 3.1 マリンエクスプレス（優先）

- **判断**: やるべき
- **手段**: Review Booster を **ケータイ（NFC等）100円** で導入できる形で提案・設置
- **狙い**: 口コミ下書き → Google投稿の摩擦を下げ、店舗側に「安い・すぐ効く」として売る／使う
- **未完メモ**: 「マリンエクスプレスの…」以降が途切れている → 次回ヒアリングで条件・単価・誰が決裁かを埋める

### 3.2 BAR REPLICA（観光客）

- レプリカに行けば **観光客** に当たる可能性あり
- 既存 Review Booster 店舗 `/bar-replica` を活かし、現場で口コミ導線・紹介・小単価の現金機会を拾う

### 3.3 小単価の積み上げ

- 1,000 / 2,000 / 3,000円を **毎回その場で取る**導線を設計する
- 「20万の大きな案件だけ」に依存しない

## 4. MIMO$A：20万ゴールと予算

### 4.1 ゴール

| 項目 | 金額 | メモ |
|------|------|------|
| MIMO$A で作る額 | **20万円** | 主目標 |
| 手元の現在額 | **8万円** | あと **12万円** |
| 持ち帰り目標（追加） | **1人10万円** | 動く量を増やす前提 |
| 購入したいものの定価感 | **50万円相当** | 実際の支出は20万枠内に収める |

### 4.2 20万の使い道（枠内パッケージ）

20万円の中で、次を **セットで**揃える：

1. **定価50万相当のもの**（機材／制作パッケージ等・要確定）を、交渉・セット割で取得
2. **MIMO$A プロモーションビデオ**
3. **ダーウィン（Da-win）のMV**

> 現在8万 → 残り12万を、上記パッケージの前金／制作費／営業キャッシュとして積み上げる。

### 4.3 不足額の埋め方（仮説・優先順）

1. マリンエクスプレス＋レプリカ等の **小〜中単価の現金**
2. MIMO$A 関連の **販売・案件・前金**
3. 広く動いて **紹介・追加案件**（単発に閉じない）

※憲法級の確定ルールにはしない。検証しながら更新する。

## 5. コンテンツ制作（資産）

| 種別 | 内容 | 用途 |
|------|------|------|
| タテ動画 | **18本** | SNS／ショート／現場再生 |
| ヨコ動画 | 本数は要確定 | YouTube／プロモ本編 |
| スチール | 本数は要確定 | サムネ・チラシ・店頭 |
| プロモPV | MIMO$A プロモーションビデオ | 営業・ブランド |
| MV | タイトリップ × Da-win 新曲 → YouTube | 拡散・タイアップ |

### 制作の進め方（案）

1. 18タテを先に回し、素材とリズムを確保
2. ヨコ・スチールはプロモ／MV用に選別・再編集
3. タイトリップ素材に Da-win 新曲を載せ、YouTube 公開
4. プロモPVとMVを「20万パッケージ」の成果物として納品・活用
