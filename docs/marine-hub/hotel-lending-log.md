# ホテル貸出管理（パンフ・チラシ）

「貸すだけ」で終わらせない。**誰に・何部・いつ補充**を1行で残す。

## ルール（最小）

1. 貸出したら**即ログ**（その場のメモ可 → 夜に転記）。
2. 残部が **5部以下** になったら補充日を入れる。
3. ホテル名はパンフQRの `?hotel=` と**同じ表記**にする（集計用）。
4. 回収・廃棄もログする（行方不明を「貸したまま」にしない）。

## ログ表（コピーして使う）

| 日付 | ホテル名（表記固定） | 媒体 | 部数 | 置き場所 | 担当フロント | 残目安 | 次回補充 | メモ |
|------|----------------------|------|------|----------|--------------|--------|----------|------|
| 例: 2026-08-03 | Waterfront Cebu | パンフ | 30 | フロント横ラック | Maria | 週次確認 | 2026-08-10 | QRは hotel=Waterfront+Cebu |
|  |  | チラシ | 20 | 同上 | 同上 |  |  | 車経由で補充可 |
|  |  |  |  |  |  |  |  |  |

媒体の値: `パンフ` / `チラシ` / `カード（名刺サイズ）`

## 車ルートと紐づけ

送迎・営業で寄るホテルは、この表の「次回補充」と**同じ日のルート**に乗せる。  
車が店舗なので、補充＝店舗の棚卸し。

## 週次チェック（15分）

- [ ] 残5部以下のホテルをリストアップ
- [ ] 印刷・持参部数を決める
- [ ] 車に積む（ドライバーに口頭＋写真で置き場所共有）
- [ ] 置いたら部数をログ更新

## やってはいけないこと

- 部数不明のまま「多分ある」で放置
- ホテルごとに違うQR（飛び先は同じ `/marine-hub`、差分は `hotel=` のみ）
- 電話番号未記入のまま大量印刷
